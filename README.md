# Firth Penalized Logistic Regression

Custom Python implementation of Firth penalized logistic regression 
with profile-likelihood confidence intervals, used in the manuscript:

"Predicting Red Breast Syndrome After ADM-Assisted Breast Reconstruction: 
An Exploratory Scoring Model Using Routine Hematologic Markers" 
(PONE-D-26-26592)

## Dependencies
- numpy
- scipy

## Usage
See `firth_regression.py` for function documentation and a runnable 
example at the bottom of the file.
